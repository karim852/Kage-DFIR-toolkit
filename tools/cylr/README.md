# CyLR

The collector. **Downloaded automatically** by the *Locate the tooling* step,
which resolves the current Windows x64 release from GitHub and unpacks it here.

Expected result: `CyLR.exe` in this folder.

To install it by hand instead:
<https://github.com/orlikoski/CyLR/releases> → `CyLR_win-x64.zip` → extract here.

The console looks in this folder first, then more widely, so a copy elsewhere
still works — but keeping it here avoids surprises.
